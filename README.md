<h2>✨ Project Overview</h2>
<p>
  DealFinder Pro is a high-performance web interface designed to help users discover deep discounts and clearance items. 
  This project focuses on a <b>premium shopping experience</b> by combining real-time data visualization with modern 
  UI/UX principles like visual hierarchy and micro-interactions.
</p>

<h2>🛠️ Technical Stack</h2>
<ul>
  <li><b>HTML5:</b> Semantic structure for accessibility and SEO.</li>
  <li><b>CSS3:</b> Custom properties (variables), Grid, and Flexbox for a robust layout.</li>
